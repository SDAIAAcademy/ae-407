# Findings: Insaf

One section per finding. A finding needs at least ten trials and a judge that reads the sandbox logs.

## F1 · (what happens, in one sentence)

| | |
|---|---|
| Objective | |
| Technique | catalogue entry |
| Rate | k of n, with the interval; script; target version |
| Severity | 1 to 4 on the impact scale, with the reason |
| Reproduce | the command, and the rows of `logs/attack_log.jsonl` |
| Trace of one success | the steps of one run |
| Proposed fix | the control, and what it does not cover |
| Regression test | the id in `regression.json`, its result on the build as found and with the fix |
